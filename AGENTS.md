# Codex project instructions

This repository is an educational, read-only simulated wallet project.

- Use Node.js 20 or newer; the project has no external dependencies.
- Check project health with `npm test`; run the demo with `npm start`.
- Do not ask for or store private keys, seed phrases, passkeys, OTPs, Binance passwords, API secrets, session cookies, or real wallet credentials.
- Do not connect real exchange or wallet accounts, sign transactions, move funds, or implement unattended trading.
- Use only fictional balances and mock services when demonstrating integration patterns.
- Explain important changes in Vietnamese.
